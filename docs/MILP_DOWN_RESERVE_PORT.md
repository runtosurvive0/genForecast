# 연간 MILP 내부 하향 여유·비용 초기해 이식

원천: national-solar-forecast `fb109c5ae6921d81ae7b63e3defda0597c4320b5`.
2026-11-01 사용자 요청: 원천에서 가져온 내부 MILP 개선을 반영하되 genForecast의
연간 수요/석탄목표·병렬 구간·2일 예열·저장/연료수급 연결은 유지한다.

## 적용 범위와 차이

- clipped `max(P−Pmin·u,0)` 하향 여유, 상·하향 부족 벌점 300만원/MW·h,
  원래 최소출력 행에서 유도한 유효 상한 cut, 완성 비용 초기해와 원래 행/경계/
  정수성 검사, 채택된 기동 이력 전달·연결 물리 검사 이식. 추가 최대 OFF 제한 없음.
- 연간 기존 입력은 `석탄목표 × scenario.reserve_ratio`다. 같은 입력 예비율을
  상·하향 정적 요구량에 사용한다. 원천의 시장수요 기준 9월 계획 p50을 연간
  총수요/순수요에 잘못 곱하지 않는다. 다른 계절에 가을 자료를 복제하지 않는다.
  이 연간 요구량 정책은 원천 55일 P3 비교와 **다른 조건**이다.
- 기존 월별 열량단가·연료곡선 최소~최대 할선 기울기와 no-load 절편·기동비,
  원전/석탄 정비·퇴출·물리 최소운전/정지·출력변동률·지역/그룹 제약 유지.
  원천의 사후 입력·기상·P/E/당진 rs3 가이드·실험 결과를 연간 데이터로 복사하지 않는다.
- 비용 초기해를 확보하기 위해 연간 단일 비용단계를 앞단 실현가능성+비용단계로
  바꾼다. 기존 quality 시간/gap 및 해 미확보 시 연간 재시도 정책은 유지한다.
  따라서 원천의 고정90초/120초/gap0.001 조건과는 다르다. 공용 highspy1.12.0을
  사용하고 병렬 작업자당 solver thread를1개로 두어 중첩 과다 병렬화를 피한다.
- 원시 상·하향 부족과 실제 solver의 보조 부족변수는 구분한다. reserve_met는
  채택된 원시 발전량 기준이며 물리검사 통과가 부족0 또는 안전 승인이라는 뜻은 아니다.
- 구간 안 롤링 연결은 검사하나, 서로 독립 초기화된 병렬 구간의 경계는 기존처럼
  예열에 의존한다. 연간 전체가 하나의 연속 MILP 해라는 보장은 하지 않는다.

## 자료·공개와 검증

추가 사내 자료·DB·계정·원천의 학습 프로필/날짜별 결과는 Git에 넣지 않는다.
공개 승인된 기존 스냅샷은 수정하지 않는다. 새 모델 학습·수집·공용 ZGX 쓰기·배포는 없다.
원천 55일 개발 결과에는 예비력 부족 악화가 있었으며 이 이식은 운영 안전 승인이 아니다.
연간 프로젝트의 수요·비용·요구량·구간 초기화가 달라 같은 DSS 정확도를 주장하지 않는다.

검증은 작은 수치/경계 회귀, 연간 전체 달력/예열/병렬 작업 조립, 저장 형식 호환,
Python 테스트와 npm test/build로 한다. 실제 전국 1년 최적화와 미래 정확도는 별도다.
