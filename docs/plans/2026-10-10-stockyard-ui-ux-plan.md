### 2.1 문제점

1. **같은 데이터가 세 번 나온다.** 60개 Pile이 약도, 혼탄 표(60행), 원장(60행)에 반복된다. 두 표가 페이지의 72%다.
2. **선택 결과가 멀다.** 약도에서 Pile을 누르면 상세는 640px 아래에 뜬다. 마우스오버 툴팁이 일부 보완하지만 터치 환경에서는 스크롤이 필요하다.
3. **발전소 선택이 두 군데다.** 상단 앱 공통 "조회 범위"와 탭 안의 발전소 칩이 따로 있다.
4. **기간 선택기가 동작하지 않는다.** 상단 30/60/90일을 눌러도 저탄장 전망은 30일 고정이다.
5. **KPI가 막다른 길이다.** "고위험 1개"를 봐도 어느 Pile인지 찾으려면 필터를 따로 조작해야 한다.
6. **조작 결과가 오해될 수 있다.** 접안 지정·이탄은 저장되지 않고 이탄은 전망에 반영되지 않는데, 화면은 반영된 것처럼 보인다.
7. **처 단위 정보가 약하다.** 백엔드 설계는 처(1~4/5~8/9~10호기)가 재고 관리 단위인데, 화면에는 처별 재고일수·처별 전망이 없다.
8. **60개 Pile 버튼이 모두 Tab 정지점이다.** 키보드로 약도를 지나가려면 60번 눌러야 한다.

## 3. 설계 원칙

1. **위에서 아래로 "지금 → 원인 → 앞으로 → 근거".** 첫 화면은 현재 상태와 문제 위치, 두 번째는 전망, 세 번째는 분석·원장.
2. **약도가 허브다.** 선박·처·Pile 선택은 약도·우측 패널·원장 표가 하나의 선택 상태를 공유한다.
3. **미리보기 → 고정 → 심화.** 마우스오버는 툴팁, 클릭은 선택 고정과 우측 패널, 패널에서 "원장에서 보기"로 심화.
4. **같은 데이터는 한 표에만.** 혼탄 결과는 원장의 열로 합친다.
5. **출처·최신성·단위·기준시각은 항상 보인다.** 배지는 `SIMULATED` / `수기` / `추정` / `예측` / `LIVE·STALE` 다섯 종으로 통일한다.
6. **"모의"와 "저장"을 구분한다.** 저장되지 않는 조작은 결과에 `모의 적용` 배지를 달고, 되돌리기를 둔다.
7. **앱 공통 규칙을 깨지 않는다.** 상단바·사이드바·색 토큰·브레이크포인트·SIMULATED 표기를 그대로 쓴다.

## 5. 영역별 상세

### 5.1 범위 바

- 앱 공통 "조회 범위"를 원천으로 하고, 탭 칩은 그 하위 선택만 보여준다. 둘이 어긋나지 않게 한다 (11장).
- 기간 30/60/90일을 저탄장 전망·입하 예정·혼탄 기간에 연결한다. 연결 전에는 저탄장 탭에서 비활성으로 보이고 "저탄장은 30일 고정" 툴팁을 단다.
- **Pile 검색**: `DA-04`처럼 입력하면 약도에서 해당 Pile로 스크롤·선택한다.

### 5.2 KPI 띠

| KPI | 표시 | 클릭 동작 |
|---|---|---|
| 총 저탄량 | t, 기준시각 | 원장으로 이동 |
| **최저 재고일수(처)** | 일, 해당 처 이름, 정상/주의/위험 색 | 패널 "처" 탭에서 해당 처 선택 |
| 가중 열량 | kcal/kg | 분석 탭 "탄종 구성" |
| 입하 예정 | t, 척수, 가중 열량 | 입하 타임라인으로 스크롤 |
| 최장 적치 | 일, Pile ID | 해당 Pile 선택 |
| 고위험 Pile | 개, SIMULATED | 위험도 필터 "높음" 적용 |

"최저 재고일수(처)"는 처별 재고를 처 소속 호기의 계획 연료로 나누는 계산이 필요하다. 계산은 `src/domain/`에 추가하고 발전소 종합과 같은 엔진을 쓴다 (12장 P2).

### 5.3 항만·저탄장 약도 (이번 브랜치에서 구현 완료, 보완점만)

- **처 헤더 강화**: 처 이름 옆에 재고(t)와 재고일수 막대, 상태색(정상/주의/위험).
- **처 선택**: 처 헤더 클릭 시 해당 처의 Pile·부두·컨베이어가 함께 강조되고 패널이 "처" 탭으로 바뀐다.
- **키보드**: 저탄장 전체를 Tab 정지점 1개로 만들고(roving tabindex), 방향키로 Pile 사이를 이동한다. Enter 선택, Esc 해제.
- **선택 연결선**: 선박을 선택하면 해당 부두 → 하역 컨베이어 → 귀속 Pile 경로를 강조한다 (현재는 Pile 밑줄만).

### 5.4 컨텍스트 패널 (현재 "선박 패널"을 확장)

| 탭 | 언제 열리나 | 내용 | 조작 |
|---|---|---|---|
| 선박 | 선박·부두 선택 | 물량·탄질·대기·접안 예정·체선료·AIS 최신성·추천 부두 | 접안 지정 (`모의 적용`) |
| 처 | 처 헤더·KPI 선택 | 재고·가중 열량·재고일수·오늘 예상 사용량·입고 예정·마지막 기준시각 | **처 간 이탄** (출발·도착·톤·시각·비고) |
| Pile | Pile·원장 행 선택 | 재고·탄질·적치·위험도·온도/CO(미연결)·투입 호기·하역 이력 | "원장에서 보기" |

- 지금 아래에 따로 있는 "Pile 상세"와 "처 간 이탄" 섹션을 이 패널로 옮긴다 → 470px 절약, 선택 결과가 같은 화면에 보인다.
- 이탄 결과는 처 탭 안에서 **적용 전/후 처 재고**를 나란히 보여주고, `모의 적용` 배지와 [되돌리기]를 둔다.
- 1050px 미만에서는 패널이 약도 아래로 내려가고, 760px 미만에서는 하단 시트(`src/components/ui/sheet.tsx`)로 연다.

### 5.5 전망 (2화면)

- **처별 재고 전망**: P1·P2·P3를 적층 영역으로, 합계선과 재고일수 위험 기준선(설정값)을 함께 표시. 기간 선택 연동. 이탄 모의 적용 시 점선으로 비교.
- **입하·하역 타임라인**: 선박별 가로 막대로 `대기 → 접안 → 하역` 구간을 표시하고 하역 완료 시점에 재고 반영 표시. 지금의 입하 예정 표를 대체한다.

### 5.6 분석 (3화면, 탭 하나로 묶음)

- **혼탄 요약**: 주간 소비량, 소진 전후 가중 열량, 처별 소진 막대, 소진 상위 10 Pile. 60행 전체 표는 원장 열로 이동.
- **탄종 구성**: 현재 도넛 유지.
- **적치·위험 산점도**: 현재 유지. 점 클릭 = Pile 선택.

### 5.7 Pile 원장 (3화면)

- 열: Pile · 처 · 구역 · 탄종 · 재고 · 열량 · 수분/회분/황분 · 적치일 · 위험도 · **주간 소진 · 잔량** · 하역 예정.
- 헤더 클릭 정렬, 상단 필터 칩(처·탄종·위험도), 20행 페이지, 고정 헤더.
- 행 클릭 = 약도·패널 선택 동기화. 선택 행 강조.
- CSV 내보내기는 현재 필터를 반영하고, 파일에 기준시각과 SIMULATED 여부를 적는다.

## 6. 상호작용 모델

### 6.1 선택 상태

화면 전체가 하나의 선택 상태를 공유한다.

```text
selection = none | { kind: "vessel", id } | { kind: "yard", id } | { kind: "pile", id }
```

| 동작 | 결과 |
|---|---|
| 마우스오버·포커스 | 툴팁 미리보기 (선택 변경 없음) |
| 클릭·Enter | 선택 고정 → 패널 탭 전환 → 약도·원장 강조 |
| Esc / 빈 곳 클릭 | 선택 해제 → 패널은 기본(도착 선박 목록) |
| 다른 대상 클릭 | 선택 교체 (다중 선택 없음) |

- 선박 선택 시 귀속 Pile 강조, 처 선택 시 처 소속 부두·컨베이어·Pile 강조.
- 범위 바 필터는 선택을 지우지 않는다. 선택 대상이 필터에 걸리면 흐리게 표시하고 패널은 유지한다.

### 6.2 URL 상태 (앱 공통)

`?plant=dangjin&select=pile:DA-04` 형식으로 선택을 주소에 남겨 공유·새로고침 후 복원한다. App 라우팅에 닿으므로 통합 담당 결정이 필요하다.

- 색만으로 상태를 전달하지 않는다. 위험도는 색 + 글자(낮음/관찰/높음), 부두는 색 점 + 상태 문구.
- 글자 크기 단계는 기존 13 / 12 / 11 / 10 / 9px을 유지한다.
- 움직임은 "실제로 흐르는 것"에만 쓴다 (하역 중 컨베이어, 상탄 벨트). `prefers-reduced-motion`이면 멈춘다.
- 배지 5종: `SIMULATED`(모의), `수기`(사람 입력), `추정`(계산), `예측`(모델), `LIVE/RECENT/ESTIMATED/STALE`(최신성).
