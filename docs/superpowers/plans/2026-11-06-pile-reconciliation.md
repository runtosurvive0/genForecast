# Pile 재고 정정 및 도면 연결 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 검증은 격리 DB에서 수행한다.

- [x] 입하 화물의 배분·잔량 정정 전후와 작성자·사유를 원자적으로 기록하고, 중복 구역·물량 불일치·오래된 revision을 거부한다.
- [x] 정정 이력과 기준재고 시각의 선후 관계를 보존하고, 수정 전 이력 조회와 수정 후 기준재고 재확인 요구를 검증한다.
- [x] Pile 원장에서 각 배분의 기존·변경 물량과 사유를 확인하며 정정할 수 있게 하고 서버 권한을 적용한다.
- [ ] 수기 원장의 확인된 Pile/셀 단위 수치를 도면과 연결하되 종단 위치가 없는 더미의 개별 위치·형상을 임의로 만들지 않는다. 사진 및 데모와 수기 자료를 구분하고 오류를 숨기지 않는다.
- [x] 격리된 API·브라우저 회귀 테스트, 기존 필수 테스트·빌드·시각 검토를 수행하고 공용 서버에는 테스트 데이터를 쓰지 않는다.
