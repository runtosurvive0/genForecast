# 상탄·혼탄 계통 화면

**Goal:** 승인된 운영 화면 톤을 유지하며 저탄장–상탄–분배–벙커–보일러를 연결한다.
**Architecture:** 기존 Three.js 저탄장·입자·뷰어를 재사용하고 보일러 모델과 읽기 전용 상태 투영을 추가한다. 기존 혼탄 분석은 별도 보기로 보존한다.
**Constraints:** 현재 작업 브랜치 유지, 사용자 변경 보존, API/재고 엔진 변경 없음, 실측 미연계 값을 만들지 않음, 1920×1080 한 화면 및 모바일/다크 유지. 커밋·push·배포 없음.

- [x] `OperationsBlend`와 전용 CSS, App 연결. 혼탄 분석과 범위 선택 유지.

## 실제 배치·외관 대조 후 수정

사용자가 기존 일반 보일러 형상 대신 구글 어스와 제공 사진을 대조하도록 요청했다. 다음 출처를 직접 확인하여 2×2 배열을 저탄장 장축과 평행한 발전동 열로 수정했다.

- Google Earth의 당진화력발전소 위성영상(표시 촬영일 2024-04-12): 저탄장과 발전동의 상대 배치, 길게 이어진 터빈동. 개별 설비 높이·치수의 근거로 쓰지 않았다.
- 사용자 `IMG_2820.JPEG` 및 원본 `coal-network-source.png`(2022-07-01 이송설비 계통도): 컨베이어 번호, 분기 타워, 호기 연결. 원본 이미지는 저장소에 복사하지 않았다.
- [충청뉴스 당진발전본부 전경, 2022-06-22](https://www.ccnnews.co.kr/news/articleView.html?idxno=260858): 흰 외벽, 푸른 세로 패널, 계단형 상부와 가느다란 굴뚝.
- [경남기업 플랜트 실적의 당진 9·10호기](https://www.kne.co.kr/eng/business/plant.asp): 두 발전동의 흰 박스형 외피, 좁은 파란 수직 띠, 긴 터빈동과 지붕 채광부.

TT-95는 3저탄장 반입 연결로 유지하며 반출 출발점으로 사용하지 않는다. RE-91A/B/C/D를 반출측에 표현한다. A/B·C/D는 두 개의 물리적인 컨베이어 데크로 표현한다. CV-62A와 CV-56C/D 교차 공급은 설명에 남기며 임의 절환 상태를 만들지 않는다.

외관·상대 위치는 출처를 반영하되 건물 치수와 노출된 벙커·급탄기·미분기 내부는 개념 표현이다. 이후 사용자 확인에 따라 모든 호기의 사일로는 **호기당 6개**로 수정했다. 각 사일로 바로 아래 작은 Coal Feeder, 그 아래 미분기를 연결하며 상부 분배 컨베이어가 여섯 투입구까지 닿도록 배치한다. 개수와 상하 연결 순서는 사용자 제공 정보이며 세부 치수·간격은 개념 표현이다. 공유 저탄장 재고·형상과 모사 신호 계약은 유지한다. 추가된 중간 설비에 모사 신호를 임의 생성하지 않는다.

회귀 검사는 발전동 장축, 공급 컨베이어 목록, TTT 양쪽 분기, 3저탄장 반출점과 A/B 데크가 담당 호기의 벙커 위치까지 이어지는지 확인한다. 수정 후 단위 184개·빌드·상탄 전용 UI 2개 통과. 전체 UI 결과와 최종 검토는 통합 문서에 기록한다.

## 발전동 외피·진입 경로 보정 (2026-11-06)

사용자가 표시한 Earth 영상의 건물 관계에 맞춰 `blend-lines.js`의 `blendBuildingLayout`을 장면 공통 기준으로 사용한다. 저탄장 `yardZ=-110`, 보일러 `boilerZ=-24`, 미분기룸 `millZ=0`, 터빈동 `turbineZ=20`은 **도식 좌표**이며 m 단위나 실측 배치가 아니다. 기본 보기는 기존 비스듬한 직교투영 일러스트를 유지하고 평면 보기를 별도로 제공한다.

상탄 갤러리의 평면 방향 전환은 직각으로 정리했다. 지붕 있는 접근부가 보일러 열의 빈 통로를 지나 미분기룸 상부 TTT에 닿고, 기존 호기별 분배 경로로 이어진다. CV·TTT의 연결 관계와 교차 공급 생략 조건은 위 표를 유지한다. 일반 보기에는 미분기룸·터빈동의 외벽과 지붕을 표시하고 **발전동 투시**를 켰을 때 외피와 갤러리 덮개를 열어 내부를 확인한다. 이 조작은 공유 저탄장의 **지붕 투시**와 독립적이다.

호기당 6개 사일로, 각 사일로 아래 소형 급탄기와 그 아래 미분기의 수직 연결은 유지한다. 2저탄장 왼쪽 일부 지붕·노출 철골, 3저탄장의 단일 태양광 외피도 공유 저탄장 모델에서 가져오며 내부 A/B 구획과 재고는 변경하지 않는다. 외피와 장면 재질은 기존 운영 UI의 토큰·글꼴·선택 규칙을 대체하지 않는다.

구조 회귀는 건물 띠의 앞뒤 순서, 보일러 사이 접근부, 직각 갤러리, 외피 투시와 저탄장 투시의 독립성 및 사일로 연결을 확인한다. 로컬 검토 자료는 `.impeccable/review/blend/`의 세 계통 일반·평면·투시, 사일로 확대, 다크·좁은 화면 캡처다. 위성영상의 촬영 시점·참고 범위는 [설비 참고 기록](../../../src/data/fuel-reference/EQUIPMENT_REFERENCES.md)에, 최신 전체 검사 결과는 [통합 문서](../../GEN4CAST_UI_INTEGRATION.md)에 기록한다.
