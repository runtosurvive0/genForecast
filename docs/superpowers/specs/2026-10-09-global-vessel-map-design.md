# 전 세계 선박 지도: 도트에서 상세 지도로 전환

작성일: 2026-10-09 KST · 상태: 구현 및 검증 완료

## 목표와 승인된 방향

사용자는 전 세계 도트 지도를 확대하면 점이 육지 면으로 자연스럽게 바뀌고,
국가에 관계없이 섬·해안선·항만·매립지 윤곽까지 탐색하기를 원한다.
MapLibre GL JS와 OpenFreeMap 조합, 기존의 차분한 디자인을 유지하는 방향을 승인했다.
이 문서는 구현 전 좌표계·출처·장애 동작·검증 범위를 구체화한다.

## 선택한 구조

- 온라인 지도는 MapLibre 하나의 Globe/Mercator 카메라에서 도트, 면, 항로, 선박을 그린다.
  기존 Equal Earth SVG와 온라인 지도를 확대 도중 교체하면 윤곽·위치가 어긋나므로
  정상 온라인 탐색 중에는 엔진을 교체하지 않는다. 기본은 구형 지구본이며 평면 보기로 전환할 수 있다.
- OpenFreeMap의 전 세계 벡터 타일을 사용한다. 지도 데이터는 OpenStreetMap 기반이다.
  기본색은 현재 라이트·다크 테마에 맞추고 도로·지명은 확대할 때 나타나게 한다.
- 기존 로컬 SVG 도트 지도는 단일 HTML 오프라인 모드와 WebGL/초기 지도 로딩 실패 시 사용한다.
  오프라인에서는 기존 도트 지도의 확대 한계와 상세 지도 미제공을 명확히 표시한다.
- 새 의존성은 `maplibre-gl`이다. 확대별 벡터 타일 처리와 GPU 레이어 렌더링에 필요하다.
  package.json과 package-lock.json을 함께 갱신하고 npm ci로 재현한다.
- 지도 코드·스타일은 src/features/vessels/에 둔다. 기존 VesselMapProps와
  선박 선택·상세 패널 계약은 유지하고, 다른 기능 화면을 import하지 않는다.

검토한 대안: SVG 위에 별도의 타일 지도를 교차 표시하면 투영 동기화 부담이 크다.
Cesium 3D 지구본은 이번의 2D 해상 운송·상세 확대 목적보다 기능·자원 범위가 커서 선택하지 않는다.

## 확대와 모프

- 초기 화면은 태평양 중심의 세계 범위로 맞추고, 화면 크기에 맞는 최소 배율을 계산한다.
  현재의 SVG 1~5배와 MapLibre zoom 값은 서로 다른 단위이므로 그대로 대응시키지 않는다.
- MapLibre zoom 1.25~2.75에서는 세계 도트를 현재 화면에 필요한 로컬 벡터 도트로 연속 전환한다.
  새 타일은 부모 타일의 기존 점 좌표를 유지하고 추가되는 점만 줌에 따라 서서히 표시한다.
  모든 도트는 소수 줌을 포함한 하나의 반경 곡선(zoom 0~6.25: 1.05~3.3625px)을 공유한다.
  최소 점 간격 8px보다 지름을 작게 유지한다. 이전 2px 상한은 연속 크기 증가 요청으로 대체했다.
  옅은 육지 윤곽은 zoom 1.5부터 나타나고, zoom 4.75~6.25에서는 도트 불투명도를 줄이며 면 지도를 드러낸다.
  zoom 6.25 이상에서는 벡터 면 지도가 중심이 되고, 더 확대하면 지명·도로·항만 형태가 나타난다.
  이 구간은 첫 화면 검증에서 미세 조정할 수 있는 시각적 기준이다.
- 최대 zoom 목표는 18이다. 소스의 최대 원본 레벨 이후 확대는 새 정밀도를 보장하지 않는다.
  모든 나라에 동일한 탐색 동작을 제공하지만 원본의 완성도·갱신 시점은 지역마다 다르다.
- 전환은 카메라 zoom에 연속적으로 종속된다. 확대를 멈추면 전환도 멈추고 축소하면 역전된다.
  점이 실제 해안선 밖으로 과하게 번지지 않도록 반경 증가를 제한하고 면과 교차 페이드한다.
  개별 점의 꼭짓점을 해안선 꼭짓점으로 옮기는 기하학적 변형은 사용하지 않는다.
- 첫 지도 준비 전 도트 배경을 없애지 않는다. 이후의 타일 로딩과 시각 전환 상태를 분리한다. 모션 감소 설정에서는 추가 시간 기반
  전환과 카메라 비행을 생략한다. 도트·면·선박 모두 같은 카메라를 사용한다.
- 확대/축소/전체 보기 버튼, 휠, 터치와 키보드 조작을 제공한다.

## 선박과 운송 정보

- 기존 positions 입력과 Shipment/Plant 계약을 그대로 소비한다. AISStream 연결은 별도 작업이다.
  샘플 위치·예시 항로·최종 수신시각·STALE 표시를 유지한다.
- 선택된 선박은 가장 위에 표시한다. 선박 마커와 목록 모두 키보드 선택을 지원하고
  화면 범위 변경·테마 전환·지도 준비 완료 후에도 선택 항차가 유지된다.
- 200척 입력, 알려지지 않은 항차에 예시 항로를 만들지 않는 동작을 유지한다.
  선박 아이콘의 화면 크기를 일정하게 유지하며 날짜변경선 부근 항로가 지구를 가로질러
  잘못 이어지지 않도록 경도 연속성을 처리한다.
- 재고·ETA·하역·발전량 계산, 백엔드와 공통 데이터 계약은 변경하지 않는다.

## 출처 표시

- 온라인 지도 왼쪽 위에 배경이 투명한 출처 링크를 항상 노출한다.
  기본 내용은 `Powered by OpenFreeMap · © OpenMapTiles · © OpenStreetMap`다.
  OpenFreeMap 표기는 권장이지만 이번 UI에는 포함한다.
- OSM 링크는 https://www.openstreetmap.org/copyright 로 연결한다.
  지도 소스에 추가 출처가 있으면 MapLibre AttributionControl이 제공하는 문구도 보존한다.
  출처 컨트롤은 자동 축소하지 않도록 설정한다.
- 오른쪽 위에는 확대·축소·리셋 다음 지구본·평면을 한 줄로 배치한다. 지도 폭 560px 이하에서는 출처 아래 둘째 줄로 도구 모음을 내린다. 도움말은 왼쪽 아래 8px, 지도 중심 기준 m/km 축척 막대는 오른쪽 아래 8px에 둔다. 상태 안내는 그 위에 표시한다. 가로 넘침·버튼 겹침을
  방지한다. 사용자가 선택한 10px 글자와 라이트 #646464를 적용하고 다크에서는 밝은 회색을 쓴다.
- 오프라인 SVG 모드에서는 기존 도트 지도 출처를 표시한다. 실제 사용하지 않는
  온라인 지도 소스를 현재 지도 원천처럼 표시하지 않는다.
- THIRD_PARTY_NOTICES.md에 MapLibre, OpenFreeMap, OpenMapTiles, OSM 출처·라이선스를 기록한다.
  지도 위 출처를 문서의 출처만으로 대체하지 않는다.

## 로딩·실패·빌드

- 로컬 자산과 컴포넌트를 먼저 준비한 뒤 import를 연결해 개발 중 Vite 누락 파일 오류를 줄인다.
- 초기 스타일 로딩 실패, WebGL 미지원 또는 복구 불가 context loss는 안내와 함께 로컬 SVG로
  전환한다. 온라인 재시도 버튼을 제공하고 재시도 횟수를 자동으로 무한 증가시키지 않는다.
- 첫 지도 준비 이후에는 신규 타일 요청 때문에 모프를 되돌리지 않는다. MapLibre가 이전 타일을
  유지하며 상세 타일로 교체한다. 일부 요청 실패도 지도를 초기화하지 않고 안내와 타일 재시도를
  제공한다. 초기 연결 실패 또는 WebGL 상실만 로컬 SVG로 전환한다.
- 외부 지도 요청은 현재 화면 탐색에 필요한 스타일·타일·글꼴·스프라이트로 한정한다.
  전 세계 타일을 저장소나 단일 HTML에 넣지 않으며, 지도 상세 보기에는 인터넷이 필요하다.
- 라이브러리는 npm으로 설치하고 외부 CDN 스크립트를 추가하지 않는다.
  Vite worker 번들 방식과 vite-plugin-singlefile의 호환성을 실제 빌드에서 확인한다.
  file: 실행은 외부 worker/타일 요청 없이 로컬 SVG를 열어 기존 오프라인 기능을 유지한다.
- 위성영상·3D 지형·실시간 위성 촬영·실시간 AIS는 이번 구현 범위에 포함하지 않는다.

## 검증과 완료 조건

1. 단위 회귀: 확대 단계·모프 경계, 선택·좌표 변환, 날짜변경선 경로 처리.
2. 브라우저 회귀: 도트→면→상세 확대 및 역전, 출처 링크/가독성/겹침,
   버튼·휠·터치·키보드, 200척, 발전소 필터, 테마 전환, 모션 감소, 컴포넌트 재진입.
3. 외부망과 독립적인 스타일·타일 fixture로 온라인 지도 동작을 검증한다.
   엔진을 통째로 mock해 실제 렌더링을 검증하지 못하는 테스트는 쓰지 않는다.
4. 실제 OpenFreeMap 연결은 한국 당진·호주 뉴캐슬·인도네시아 공급항·네덜란드 로테르담에서
   수동 확인한다. 데이터 부족이나 서비스 장애는 테스트 성공으로 대체하지 않고 보고한다.
5. 320/390/768/1440px 화면, 네트워크 차단, 초기 스타일 실패, WebGL 미지원,
   단일 HTML 오프라인 실행을 확인한다.
6. npm test, npm run build, npm run test:ui, git diff --check 및 변경 diff 검토를 수행한다.
   기존 SVG 회귀는 오프라인 경로에서 유지하고 온라인 지도 회귀를 추가한다.
7. 공통 UI·지도 자산·의존성·라이선스 문서 변경은 최종 보고와 향후 PR에 명시한다.
   사용자 요청 전 커밋·push·PR·merge는 수행하지 않는다.

### 사용자 피드백 반영 (2026-10-09)

- 기본 지구본은 짧은 화면 변 길이에 맞춰 구 전체 윤곽을 표시한다. 우상단에서 평면으로 전환하고 테마 변경 시 선택을 유지한다. 지구 뒤편 마커는 보이지도 클릭되지도 않는다.
- 점은 전체 확대 구간에서 연속 증가한다(반경 1.05~3.3625px). 정수 줌 경계에서도 크기가 초기화되지 않으며, 새 점의 등장과 면 전환은 불투명도로 처리한다. 물 레이어를 점 위에 두어 실제 해안선을 따른다.
- 평면용으로 별도 Mercator 격자 데이터를 생성한다. 기존 위도 등간격 점을 평면에 투영할 때 발생하던 북쪽 줄무늬를 방지한다. 메르카토르 자체의 고위도 면적 확대는 남는다.
- 지도 이동과 타일 재시도 중 카메라/선박 선택/면 전환을 유지한다. 실제 타일 4건에 지연을 주고 렌더 프레임의 모프 값이 1을 유지하는 것을 확인했다.

### 다크 지구본 배경 (2026-10-09)

- 지구 바깥 여백에만 1~1.4 CSS px의 작은 사각 별을 낮은 불투명도로 그린다. 라이트·평면에서는 숨긴다.
- 고정 seed의 구면 방향을 현재 카메라 방향에 투영한다. 드래그에 연동하고 같은 시점으로 복귀하면 같은 패턴이 된다. 별의 크기는 확대 배율에 따라 커지지 않는다.
- 현재의 pitch/roll 0 지구본 카메라 제약을 사용한다. 지도 render 이벤트에서 시점이나 크기가 바뀔 때만 다시 그리며, 독립 애니메이션·깜빡임·지도 repaint 요청은 없다. 장식용 별이며 천문 관측 정보가 아니다.
