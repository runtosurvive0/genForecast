# Open Waters 보조 AIS 수신

사용자가 승인한 방식은 AISstream 유지 + Open Waters 보조 수신이다. 당진·평택 주변 실제 관측 공백을 보완하며, 관심 등록·항적·기상·지도가 동일 MMSI를 사용한다.

## 접근 방식과 범위
- AISstream 교체는 기존 전 세계 수신을 잃으므로 제외한다.
- 별도 제공처 선택만 추가하면 지도와 관심 항적이 분리되므로 제외한다.
- 서버 수집 단계에서 병합한다. 기존 `aisstream` source와 `ais-<MMSI>`는 호환용 컬렉션 식별자로 유지한다. 실제 위치 제공처는 선택적 `ais.position.feed`와 `upstream`으로 명시한다. 기존 계정 목록을 이전할 필요가 없다.
- 최초 범위는 북위 36.8~37.2, 동경 126.4~126.9. 다른 지역은 설정으로 제한적으로 확장한다. 전 세계 보완을 보장하지 않는다.

## 동작
- ZGX 수명주기에 독립 수신 작업을 시작하고 종료한다. HTTP 조회나 로그인에 의존하지 않는다.
- 기존 12만 척 SQLite 저장·MMSI 병합·관심 항적 경로를 공유한다. 최신 위치 시각만 채택하며 정적 정보가 위치 시각을 갱신하지 않는다.
- Open Waters 원본 event의 time과 message를 검증한다. 미래/누락 시각, 잘못된 좌표, 미지원 종류, 원본 메시지 ID/NMEA가 없는 캐시 재구성 이벤트는 채택하지 않는다. AISHub 등 알려진 공급원의 JSON 재인코딩(synthesized=true)은 실제 관측이며 원본 시각·출처·reencoded 표시를 보존해 허용한다. envelope의 마지막 좌표를 정적 메시지 위치로 만들지 않는다.
- 한 공급원 오류가 다른 공급원의 수집을 중단하지 않는다. 공급원별 상태·시각을 API에 추가한다. 제공처 오류 원문/토큰을 브라우저와 로그에 노출하지 않는다.
- UI 구조는 유지하고 제공처 명칭과 출처 링크를 표시한다. AISstream으로 잘못 표시하지 않는다.
- OPENWATERS_ENABLED=1로 명시적으로 활성화한다. 토큰은 선택적 서버 환경변수이며 AISstream 키를 재사용하지 않는다. 공개 API 익명 조회가 가능하다는 사실은 팀/상업 이용 허가를 뜻하지 않는다. ZGX 상시 활성화 전 이용 범위를 확인한다.

## 검증
역순·중복·동시 공급원, 정적 갱신, 잘못된/재구성 메시지, 재시작 복원, 브라우저 없는 수집, 연결 실패 격리, 출처 보존을 격리 DB로 검증한다. 실제 스트림은 별도 일회성 프로브에서 검증하며 운영 DB에 테스트 자료를 넣지 않는다.
