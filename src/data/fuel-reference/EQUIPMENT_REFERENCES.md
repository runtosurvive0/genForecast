# 설비 형상·배치 참고 기록

접안·저탄·혼탄의 3D 장면은 기존 운영 UI 안의 아이소메트릭 일러스트다. 사진과 위성영상에서 판독한 상대 배치, 사용자 계통도에서 읽은 연결 관계, 사용자 확인 수량을 구분해 사용한다. 영상이나 3D 형상에서 현재 운전 신호·정확한 치수·재고 용량을 추론하지 않는다.

전경 기사·시공사 사진의 원문 링크와 계통별 컨베이어 목록은 [상탄·혼탄 구현 기록](../../../docs/superpowers/plans/2026-11-05-blend-scene.md)에 있다. 사용자 원본 이미지는 로컬 참고 자료이며 이 기록을 위해 저장소에 복사하지 않았다. 제공·열람 사실을 공개 배포 승인으로 간주하지 않는다. 촬영일은 Google Earth 탭의 표시를 따른 것이며 두 이미지 파일의 촬영 메타데이터를 별도로 검증한 것은 아니다.

## 형상과 데이터 경계

- `berth-site-layout.js`의 `harbourLayout`·`harbourPoint`는 접안 전체도용 표시 좌표다. 1저탄장 장축 1.3배 확대와 3저탄장 위치 이동을 설비·선박·더미·입자·낙탄 목표점에 같은 기준으로 적용한다. 저탄장 상세 좌표와 2저탄장 치수 보정, 원본 연결 그래프·재고 계산에는 적용하지 않는다.
- `berth-harbour.js`는 두 연결교와 짧은 1부두·긴 2·3부두, 말뚝·레일·방충재·계선 돌핀·보행로·갤러리 덮개를 표현한다. 좌우는 장면의 기본 방향 기준이다. 반복 부재와 해안 단면은 참고 외관을 읽기 위한 개념 형상이다.
- 2저탄장 지붕의 왼쪽 약 25%는 영상에 맞춘 시각적 범위다. 3저탄장의 단일 외피 아래에도 기존 A/B 저장 구역을 유지한다. 두 외피는 접안·저탄·혼탄에서 공유하며, 투시 여부는 각 뷰와 조작 상태에 따른다.
- `blend-lines.js`의 건물 배치 좌표와 `blend-model.js`의 지붕 있는 직각 접근 갤러리·미분기룸·터빈동 외피는 상대 관계의 표현이다. **발전동 투시**가 내부 사일로·급탄기·미분기를 드러내며, 저탄장 **지붕 투시**와는 독립적이다.
- 장면 자료는 ZGX 실제 AIS·수급 원장과 로컬 운전 모사를 대신하지 않는다. 외관 변경으로 새 센서 신호·완료 시각·설비 가동 상태를 만들지 않는다. 현재 상태와 연결 지연 처리는 기존 계약을 따른다.

기존 `DESIGN.md`와 `.impeccable/design.json`의 정체성·UI 토큰을 유지하는 일반 확장이다. 참고 외관과 회귀 검사·검토 캡처는 실측 인증 또는 운영 승인이 아니다. 전체 실행 결과는 [통합 문서](../../../docs/GEN4CAST_UI_INTEGRATION.md)에 기록한다.
